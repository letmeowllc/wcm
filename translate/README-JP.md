# プログラムについて
**LetMeow** による **Windows Cat Manager** アプリケーションは、小さいながらも便利な機能のために設計されています：
| 機能 | 説明 |
| :--- | :--- |
| **自動起動** | 特定のファイルやプログラムを特定の時間に開くようにする |
| **バックアップ** | 自動バックアップを作成する |
| **クリーニング** | 一時ファイルとごみ箱をクリーンアップする |
| **アプリのインストール** | 1つのバージョンではインターネットなしでアプリをインストールし、もう1つではそれを使用する |
| **リマインダー** | 独自のリマインダーを作成する |

---

# インストール
1. 最新のリリースに移動します。
2. アプリあり、またはアプリなしのバージョンをダウンロードします（詳細はリリースノートに記載されています）。
3. 取得した zip アーカイブを開き、**管理者として** setup.bat ファイルを実行します。

# FAQ（よくある質問）

<details>
<summary><b>WCM の使用は安全ですか？</b></summary>
はい。プログラムはオープンソースコードで書かれています。スクリプトは個人データを収集したり、インターネットに送信したりしません。ファイルを削除する前に、プログラムは常に確認を求めます。
</details>

<details>
<summary><b>サイズの小さいバージョンと大きいバージョンの違いは何ですか？</b></summary>
最初のバージョンではアプリがダウンロードされ、2番目のバージョンではインストーラーが既に含まれています。
</details>

<details>
<summary><b>プログラムをアンインストールできますか？</b></summary>
はい、アンインストールできます。
</details>
