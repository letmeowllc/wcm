# About the program
The **Windows Cat Manager** application by **LetMeow** is designed for small but useful functions:
| Function | Description |
| :--- | :--- |
| **Autostart** | Make a specific file or program open at a specific time |
| **Backups** | Create automatic backups |
| **Cleaning** | Cleaning temporary files and recycle bin |
| **App installation** | Installing apps without the internet in one version, and with it in another |
| **Reminders** | Create your own reminders |

---

# Installation
1. Go to the latest release.
2. Download the version with apps or without (more info in the release notes).
3. Open the resulting zip archive and run the setup.bat file **as administrator**.

# FAQ (Frequently Asked Questions)

<details>
<summary><b>Is it safe to use WCM?</b></summary>
Yes. The program is written with open source code. The scripts do not collect your personal data or send it to the internet. Before deleting files, the program always asks for confirmation.
</details>

<details>
<summary><b>What is the difference between the smaller version and the larger version?</b></summary>
In the first version, apps are downloaded, while in the second, the installers are already included.
</details>

<details>
<summary><b>Can I uninstall the program?</b></summary>
Yes, it can be uninstalled.
</details>
