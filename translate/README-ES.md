# Acerca del programa
La aplicación **Windows Cat Manager** de **LetMeow** está diseñada para funciones pequeñas pero útiles:
| Función | Descripción |
| :--- | :--- |
| **Inicio automático** | Haz que un archivo o programa específico se abra en un momento específico |
| **Copias de seguridad** | Crea copias de seguridad automáticas |
| **Limpieza** | Limpieza de archivos temporales y papelera de reciclaje |
| **Instalación de apps** | Instalación de apps sin internet en una versión, y con él en otra |
| **Recordatorios** | Crea tus propios recordatorios |

---

# Instalación
1. Ve a la última versión.
2. Descarga la versión con apps o sin ellas (más información en las notas de la versión).
3. Abre el archivo zip resultante y ejecuta el archivo setup.bat **como administrador**.

# FAQ (Preguntas frecuentes)

<details>
<summary><b>¿Es seguro usar WCM?</b></summary>
Sí. El programa está escrito con código de código abierto. Los scripts no recopilan tus datos personales ni los envían a Internet. Antes de eliminar archivos, el programa siempre pide confirmación.
</details>

<details>
<summary><b>¿Cuál es la diferencia entre la versión más pequeña y la más grande?</b></summary>
En la primera versión se descargan las apps, mientras que en la segunda los instaladores ya están incluidos.
</details>

<details>
<summary><b>¿Puedo desinstalar el programa?</b></summary>
Sí, se puede desinstalar.
</details>
