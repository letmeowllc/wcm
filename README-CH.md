# 关于程序
**LetMeow** 的 **Windows Cat Manager** 应用程序专为小型但实用的功能而设计：
| 功能 | 描述 |
| :--- | :--- |
| **自动启动** | 让特定的文件或程序在特定时间打开 |
| **备份** | 创建自动备份 |
| **清理** | 清理临时文件和回收站 |
| **应用程序安装** | 一个版本无需互联网安装应用程序，另一个版本则需要 |
| **提醒** | 创建您自己的提醒 |

---

# 安装
1. 前往最新版本。
2. 下载带应用或不带应用的版本（更多信息请参阅发布说明）。
3. 打开得到的 zip 压缩包，并 **以管理员身份** 运行 setup.bat 文件。

# 常见问题

<details>
<summary><b>使用 WCM 安全吗？</b></summary>
是的。该程序使用开源代码编写。脚本不会收集您的个人数据，也不会将其发送到互联网。在删除文件之前，程序总是会请求确认。
</details>

<details>
<summary><b>较小版本和较大版本有什么区别？</b></summary>
在第一个版本中，应用程序是下载的，而在第二个版本中，安装程序已经包含在内。
</details>

<details>
<summary><b>我可以卸载这个程序吗？</b></summary>
是的，它可以被卸载。
</details>
