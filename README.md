# О программе
Приложение **Windows Cat Manager** от **LetMeow** создано для маленьких, но полезных функций:
| Функция | Описание |
| :--- | :--- |
| **Автозапуск** | Сделайте так, чтобы открывался определённый файл или программа открывались в определённое время |
| **Бекапы** | Создайте автоматические бекапы |
| **Чистка** | Очистка временный файлов и корзины |
| **Установка приложений** | Установка приложений без интернета в одной версии, и с ним в другой |
| **Напоминания** | Создавайте свои напоминания |

---

# Установка
1. Зайдите в последний релиз.
2. Скачайте версию с приложениями или без (дополнительная информация в заметках о релизе).
3. Зайдите в полученный zip-архив и откройте файл setup.bat **от имени администратора**.

# FAQ (Частые вопросы)

<details>
<summary><b>Безопасно ли использовать WCM?</b></summary>
Да. Программа написана с открытым исходным кодом. Скрипты не собирают ваши личные данные и не отправляют их в интернет. Перед удалением файлов программа всегда спрашивает подтверждение.
</details>

<details>
<summary><b>Чем отличается версия, которая весит меньше от версии, которая весит больше?</b></summary>
В первой версии приложения скачиваются, а во второй установщики уже есть.
</details>

<details>
<summary><b>Можно ли удалить программу?</b></summary>
Да, её можно удалить.
</details>
