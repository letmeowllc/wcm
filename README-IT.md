# Informazioni sul programma
L'applicazione **Windows Cat Manager** di **LetMeow** è progettata per funzioni piccole ma utili:
| Funzione | Descrizione |
| :--- | :--- |
| **Avvio automatico** | Fai in modo che un file o un programma specifico si apra in un momento specifico |
| **Backup** | Crea backup automatici |
| **Pulizia** | Pulizia dei file temporanei e del cestino |
| **Installazione app** | Installazione di app senza internet in una versione, e con esso in un'altra |
| **Promemoria** | Crea i tuoi promemoria |

---

# Installazione
1. Vai all'ultima versione.
2. Scarica la versione con le app o senza (maggiori informazioni nelle note di rilascio).
3. Apri l'archivio zip risultante ed esegui il file setup.bat **come amministratore**.

# FAQ (Domande frequenti)

<details>
<summary><b>È sicuro usare WCM?</b></summary>
Sì. Il programma è scritto con codice open source. Gli script non raccolgono i tuoi dati personali né li inviano a Internet. Prima di eliminare i file, il programma chiede sempre conferma.
</details>

<details>
<summary><b>Qual è la differenza tra la versione più piccola e quella più grande?</b></summary>
Nella prima versione le app vengono scaricate, mentre nella seconda gli installer sono già inclusi.
</details>

<details>
<summary><b>Posso disinstallare il programma?</b></summary>
Sì, può essere disinstallato.
</details>
